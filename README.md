# 🏡 WanderStay

WanderStay is a full-stack vacation rental platform inspired by modern accommodation booking websites. Users can browse unique stays, create their own listings, upload property images, leave reviews, and manage listings securely through authentication.

## 🚀 Features

- User Authentication & Authorization
- Create, Read, Update & Delete Listings
- Image Upload Support
- Property Reviews & Ratings
- Secure Login & Registration
- Flash Messages
- Server-side Validation
- Responsive UI
- RESTful Routing
- MongoDB Database Integration
- exact location using map

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/username/WanderStay.git
```

Navigate to the project

```bash
cd WanderStay
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```
ATLASDB_URL=
CLOUD_NAME=
CLOUD_API_KEY=
CLOUD_API_SECRET=
SECRET=
```

Start the server

```bash
node app.js
```

or

```bash
npm start
```

Visit

```
http://localhost:8080/listings
```
